<자바>
자바는 1995년 Sun Microsystems의 제임스 고슬링과 동료들이 개발한 객체 지향 프로그래밍 언어입니다.

<자바의 특징>
WORA (Write Once, Run Anywhere)
- 한 번 작성하면 어디에서든 실행 가능한 운영체제 독립성
옛날에는 아이폰용 앱과 안드로이드용 앱을 완전히 따로 만들어야 해서 개발자들이 힘들었음
그런데 자바는 ‘자바 가상 머신(JVM)’ 이라는 만능 번역가를 데리고 다님. 개발자는 자바로 글을 한 번만 쓰면, 윈도우든 맥이든 리눅스든 각 운영체제에 맞는 JVM 번역가가 알아서 그 나라 말로 통역해 줌. 개발자가 OS 신경 안 쓰고 프로그램 하나만 만들면 끝나는 특징이 있음

2. 객체 지향 (Object-Oriented Programming, OOP)
- 모든 것을 객체 중심으로 생각하고 설계하는 프로그래밍 패러다임 채택
 레고 블록으로 자동차를 만든다고 생각해 보면, 
바퀴 블록, 유리창 블록, 엔진 블록을 각각 따로 조립해서 하나의 멋진 자동차를 완성함.
자바도 똑같습니다. 회원 관리 블록, 결제 블록, 상품 검색 블록을 각각 ‘객체’ 라는 조립식 부품으로 만들어 두고, 필요할 때 조립해서 거대한 프로그램을 만듦.

<자바의 장점>
강력한 안정성
- 가비지 컬렉션, 예외 처리 등 안정적인 메모리 관리 가능
C언어 같은 옛날 언어들은 개발자가 방을 쓰고 나면 직접 청소를 해야 했음. 청소를 까먹으면 컴퓨터 메모리가 가득 차서 프로그램이 뻗어버렸음.
하지만 자바는 ‘가비지 컬렉터’라는 자동 청소 로봇이 등판하는데 프로그램 안에서 더 이상 쓰지 않는 쓰레기 데이터를 알아서 찾아서 지워주기 때문에, 개발자가 실수해도 프로그램이 쉽게 죽지 않고 안전하게 돌아감.

2.  방대한 라이브러리와 활발한 커뮤니티
이미 만들어진 수많은 기능으로 편리한 개발과 활발한 자료 공유
자바에는 전 세계 천재 개발자들이 미리 만들어둔 밀키트 같은 ‘라이브러리’가 많음. 로그인 기능, 엑셀 다운로드 기능 등을 가져다 쓰기만 하면 됨. 하다가 막히는 건 구글이나 네이버에 검색하면 이미 수많은 사람들이 답을 남겨놓아서 쉽게 해결할 수 있음.

<자바의 단점>
1. 코드가 너무 길고 복잡하다 (비효율적인 문장 구조)
자바는 규칙과 형식을 아주 깐깐하게 따지는 언어임. 그래서 다른 언어(파이썬 등)라면 단 한 줄로 끝낼 수 있는 간단한 명령도, 자바에서는 클래스 선언, 메인 메서드 등 정해진 틀을 맞추느라 대여섯 줄씩 길게 적어야 함. 이 때문에 처음 배울 때 직관적으로 코드를 이해하기 어렵고 타자 칠 게 많아짐.

2. 메모리를 많이 먹고 실행 속도가 상대적으로 느리다
자바는 컴퓨터가 코드를 직접 읽는 게 아니라, 중간에 JVM(자바 가상 머신)이라는 '통역사'를 거쳐서 실행됨. 또한, 뒤에서 쓰레기 데이터를 대신 치워주는 자동 청소부(가비지 컬렉터)도 항상 켜져 있어야 함. 이 시스템들을 유지하느라 컴퓨터 메모리(RAM)를 많이 차지하고, C언어처럼 컴퓨터와 직접 대화하는 언어에 비해 초기 실행 속도가 살짝 느림.
